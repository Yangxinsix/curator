Using models for simulations
============================

When model training is finished, you can use the models for simulations. CURATOR currently supports ASE calculator and LAMMPS for different simulation tasks.

We pre-defined some simulation parameters which mostly aim to support some common simulation tasks that can be conducted in ASE or LAMMPS. 

Considering the massive number of simulations that machine learning potentials can be used for, it is also possible for the users to define a class that is capable of running simulations they would like to perform.
