# Cumulene 方向传输：十臂训练规则

训练来自同一个 C9H4 化学门控 STF 80,000 步父模型。只使用元素、坐标及原 ACVR 边界输入；不得将端基、扭角或扫描点传进训练模型。训练集 2,000、普通验证集 500、历史测试集 2,473；公开刚性扫描 1,000 帧作为曲线诊断。五个输入已在本目录 inputs 中固定。使用同一初始化种子和 batch 顺序比较每个种子下的所有模型。同一完整网络内的确定性初始化（方向分支）与每个 batch 的顺序应使用各自受控的生成器。2,500、10,000 指从父模型起的新增更新，分别为联合步骤 82,500 与 90,000。同一 10k 学习率日程、batch 16；等更新次数，并记录实际耗时。能量/力训练物理模型；SOAP 只用原驻定残差更新 proposal。无电荷或力矩标签，推理一次前向。

| 组 | 方向或融合改动 |
| --- | --- |
| B0 | 原 80k 模型原样续训 |
| B1 | 同阶传输及容量对照，不新增显式的位移角耦合 |
| T20 | B1 + 张量到标量（位移 L=2） |
| T02 | B1 + 标量到张量（L=2） |
| T22 | B1 + 张量到张量（L=2） |
| V11 | B1 + 向量到向量（L=2） |
| O1 | B1 + 全部四条位移 L=1 路径 |
| J2 | 所有 L≤2 的 11 条路径，包含 B1 |
| B1H | B1 同时回写 DPA4C 局域矩再做不变量收缩 |
| J2H | J2 同时回写 DPA4C 局域矩再做不变量收缩 |

**事先固定的筛选**：初筛种子 3407。2,500 仅检查状态及完整评分，不筛选。到 10,000 步对照 B0，普通验证集 90°≤角度<150° 的力矩 RMSE 与刚性扫描同区间的力矩 RMSE 两者都不得高于 B0。在同时守住两项的候选中按全部 500 帧的普通验证力矩 RMSE 从小到大选两组；与基线持平/未赢时不称为改善。若不足两组达标，剩余复验位置给相对 B0 的最大低角超幅最小者，明确标为诊断候选，不宣称低角合格。相同分数用 arm 名称打破平局。全部 500 帧均计入主指标；普通验证角区样本数分别为 <90°:43，[90°,150°):289，[150°,170°):116，[170°,175°):30，[175°,180°]:22。

**复验**：两名候选和原基线 B0 各从同一父权重重新训练于三个新配对种子 3408/3409/3410；不继承初筛终点。比较候选与同种子 B0 的差，报告三个差值及均值、样本标准差和两个低角条件同时通过的种子数。初筛种子不混入确认统计。用普通验证标签以外的历史测试成绩排序无效。验证能量、力、驻定误差、低/高角扫描及相对能量完整保留。历史测试此前已被查看，不作为全新盲测证据。
