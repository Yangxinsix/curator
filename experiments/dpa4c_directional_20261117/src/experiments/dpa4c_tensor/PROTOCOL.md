# DPA4C-Small + ACVR：角动量进入 Q/K 还是 Value

本轮是已有模型的配对续训，不是七个新底座。每体系从上一轮 seed 3407 第 20,000 联合更新步的相同模型、Adam 和 SOAP 状态分叉。AuMgO 使用 A3（四组增益周期 RSA），SA-SA 使用 B2，其余使用各体系 B2 扩展检查点。逐一核对端点 SHA256、数据划分、训练参考和优化器状态；旧任务目录只读。

| 组别 | Q/K 的角分量数 | 新方向 Value | 新能量项 |
|---|---:|---|---|
| old | 4 | 无 | 无 |
| qk2 | 9 | 无 | 无 |
| orient2 | 4 | 4 个二阶通道，每通道 5 分量 | 本地张量和远端张量的内积 |
| orient12，仅 Cumulene | 4 | 8 个一阶通道及 4 个二阶通道 | 本地向量/张量与远端向量/张量的内积 |

原 Q/K 的角分量包括每个原子原有的 1 个标量分量、3 个向量分量；qk2 额外加入 5 个二阶分量。二阶数据取自 DPA4C 已有的原始二阶矩，不把不变的局部描述符冒充二阶张量。qk2 只把新 Query 投影置零，Key 保持非零；补偿 4→9 的原核归一化。Value 组共享原 Q/K 及其位置编码，新增投影不为零而读出权重从零起步。计算使用分解形式，并在原子因子上减去自消息；无原子方阵。单原子不会得到来自自身取向的附加能量。

每组追加相同的 20,000 步，沿原训练流的第 20,000 步继续取结构，batch=4。Adam 更新主干和能量头，仅用能量和力；SOAP 仅以原驻定残差更新 proposal。不增加电荷、偶极或扭矩标签。保留原来的纯 DPA4C 对照作为历史数据，不将它伪报成同预算重训臂。生产推理为单次前向；Newton 只用于检验。各新组仅对新参数使用新的 Adam 状态。当量子数增加时有额外计算成本，同步数不等于同时间，记录实际秒数和 300/600/900 s 快照。

终点对完整验证及独立测试计算能量、力、驻定 RMS、均匀电荷钳制结果；Newton 只取固定子集。SA-SA 和 SA-BS 用留出的 DFT 偶极评估。Cumulene 的 1,000 个真实 E/F 扭转扫描构型独立于训练；对同一检查点分别直接预测 q 和钳 q=0，比较相对能量、势垒和沿扫描的力矩。每条曲线用相同起始构型定零，正文指标的单位为 eV/分子和 eV/rad（不是每原子 E/F RMSE）。

检验：preflight.py 使用原 Cumulene 及 AuMgO 检查点在 FP64 检查初始化一致、通用与批处理能量/力/电荷一致、姿态旋转、二阶力损失梯度以及改变新参数时钳电荷能量是否独立响应。远端额外运行真实小批的续训，验证读写检查点、优化器状态和 GPU 训练路径。
