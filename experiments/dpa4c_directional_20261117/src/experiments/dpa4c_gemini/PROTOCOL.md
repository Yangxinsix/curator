# DPA4C-Small / ACVR 七体系配对实验

## 第一轮

| 体系 | 训练 / 验证 / 独立测试 | 五组 |
|---|---|---|
| AuMgO | 4050 / 450 / 500 | A0 纯 Small；A1 共享 RSA；A2 一个可学习增益；A3 四个分组增益；A4 四组、每组四个径向系数 |
| SA-SA | 15999 / 2000 / 2000 | B0 纯 Small；B1 原方案；B2 线性驱动初值乘二；B3 联合阶段先冻结主干；B4 两项均开启 |

每个体系各建一份 seed 3407 的纯 DPA4C-Small 底座。64 个训练构型用于描述符校准，随后进行 20,000 次纯 E/F 更新。从这一份底座分叉，所有组再进行 16 次 E/F 预热和 20,000 次 E/F 更新。ACVR 组在两者之间用 64 个训练构型校准 proposal 输入，再做 64 次仅 proposal 的 SOAP 预热。联合阶段每步只把 E/F 梯度送入能量和可训练主干，只把原驻定残差送入 proposal。B3、B4 仅在联合阶段前 256 次 E/F 更新冻结主干。相同种子对应相同物理小批、有效 batch 4。所有训练数据来自原始训练折。能量参考在训练折拟合。

主干 Adam 学习率 1e-4，能量头 Adam 为 1e-5，谱增益沿用历史单独参数组 0.003，proposal SOAP 为 1e-4。训练 FP32，全精度 TF32 关闭。A2–A4 初始增益均为 1。每个模型每次正常推理只做一次前向。

## 评分和选模

分别记录 E/F RMSE、固定总电荷驻定 RMS、同模型均匀电荷钳制的 E/F、固定子集的 FP64 Newton 绝对和相对转移误差。SA-SA 另用原始 DFT 偶极作独立观测，未用于训练。验证曲线跟踪固定 32 帧、8 个 Newton 参考。端点 E/F 和钳制覆盖整个验证折，Newton 扩至 32 帧。独立测试仅在选定配置后运行。配对更新量曲线和 300、600、900 秒检查点记录实际经过的时间和设备。计时从该组分叉开始，包括各组所需的预热，不包括离线验证和一次性纯底座。

首轮使用 seed 3407；3408、3409 改变头部初始化和小批顺序，三者共用每体系已经训练好的同一个底座。筛选按完整验证力 RMSE，预设实用等效容差 0.2 meV/Å。三个种子的分布不包含重新训练底座带来的方差。筛选规则、验证 ID 和数据集大小在 followup.py 中固定。独立测试包含纯主干和选定 ACVR。

## 扩展

首轮的两个体系完成独立测试后，调度 NaCl 和 SA-BS 的纯 DPA4C、选定分子 ACVR、DPA4C+官方 LES。三个臂从各自体系同一纯底座分叉，先用配对 seed 3407。两者全部验证成功后，同样的流程覆盖 Cumulene、Dimers 和 SA-DMA。测试指标不参与选取后续方案。LES 作为独立对照，其潜变量使用 LES 原定义。不同原子数的小批按尺寸分组后合并损失，在同一批上每个优化器只更新一次。Dimers 沿用原数据处理中按中性价态推断的 Q=0，源数据没有可核对的 DFT 总电荷字段。
